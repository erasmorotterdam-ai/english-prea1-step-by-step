# English Pre-A1 — Step by Step

Aplicación educativa de inglés estadounidense, nivel Pre-A1.

**Estado:** Beta 1. Basada en la versión V9 de Step by Step.

## Uso

Abrir `index.html` o visitar GitHub Pages. La reproducción de voz depende de las voces disponibles en el navegador. La práctica oral requiere un navegador compatible y permiso de micrófono.

## Publicación

En GitHub: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.

## Aviso

La aplicación no ha completado pruebas funcionales en Windows, Android e iPhone. El reconocimiento de voz no es una evaluación fonética fiable.
